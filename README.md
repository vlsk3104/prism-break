Prism Break is a neon breakout game for desktop browsers. Steer the paddle with the mouse or arrow keys, launch the ball, and shatter five hand-designed prism walls built from normal, armored, explosive and steel bricks. Chain explosions, build combos, and catch falling powerups — multi-ball, laser paddle, wide paddle, slow-time and a rare extra life — to clear every wall before your three lives run out. It features particles, screen shake, hit-stop, floating score text, synthesized sound effects and a music loop, plus title, pause, game-over and victory screens with full run stats.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
